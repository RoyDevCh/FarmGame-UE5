## 2. 明确不在本切片范围（原版有、这里没有）

- 独立 House 场景（本地图东侧是矿洞空地，不是第二个场景）
- 宠物、塔防、陷阱、洒水器、混合锅、商店 NPC 对话（商店是售卖亭面板）
- 体力/饥饿/XP、工具耐久、技能树
- 手柄/触屏、多人、排行榜
- 原版 325 张贴图 / 337 个 FBX 的完整移植（只导了 120+ 个精选模型，贴图仍是程序生成）
- 原版动画全集（只接角色 idle/run/attack、鸡/牛 idle/walk、熊 idle/run/attack）

## 3. 已知缺口（不影响主循环，但确实没做）

1. 手持工具挂点未做视觉校准（`hand_R` + 45cm、零偏移）。
2. 商店/菜单/设置没有 UI 级自动化点击测试（受窗口前台抢占限制，菜单逻辑用 PIE + Python 间接验证）。
3. Food 资产只接了 Apple/Bread 两个，其余 45 个模型未进物品表。
4. 设置没有分辨率列表、按键重绑；音量五档粗调。
5. 存档槽/音量写在 `GameUserSettings.ini`，不随游戏存档走。
6. 野猪用熊的网格与动画。
